# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-10-30

### Added

- Visitor widget with async lazy loading, Shadow DOM isolation, PC/mobile support, ad-block detection, compliance consent, announcements, FAQ, screen recording and blacklist enforcement.
- Real-time chat with visitor typing preview, file/image attachments, rating, offline messages and pre-chat forms.
- Admin workspace with conversation claim/transfer/internal notes, canned replies, visitor 360 profile, lead CRM, reports, automation rules, knowledge base, sites, widget configuration and RBAC.
- SaaS plan gating for Free, Standard, Pro and Enterprise with backend feature checks.
- Multi-tenant data isolation by `tenant_id` and `site_id`.
- Landing page with pricing, integration guide, customer cases and trial request form.
- Open API with `x-api-key` authentication for the Enterprise plan.
- DingTalk/WeCom webhook notifications and in-app notifications.
- Audit logs, rate limits, sensitive-word filtering and upload whitelist.
- API smoke tests and Playwright browser end-to-end tests.
- Architecture and API documentation in `docs/ARCHITECTURE.md`.
